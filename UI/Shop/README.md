# Shop UI source

Lege PNG-Dateien fuer die Shop-Oberflaeche direkt in diesen Ordner. Der UI-Editor findet neue Dateien beim Oeffnen von **Element hinzufuegen** automatisch.

Start:
- Windows: `Tools\Shop-UI-Editor_Windows.cmd`
- Linux: `Tools/Shop-UI-Editor_Linux.sh`

Exportiere das fertige Layout als `shop-layout.json`. Kopiere danach Layout und verwendete PNG-Dateien nach `SpaceSim.Godot/Assets/Shop/`; dieser Ordner wird spaeter vom Spiel geladen.
